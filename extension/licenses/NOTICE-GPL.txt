MediaDownloader - mode léger de l'extension Firefox : avis de licences

ffmpeg-core.wasm (dossier lite/vendor/ffmpeg/) est le paquet npm @ffmpeg/core 0.12.10 (FFmpeg compilé en
WebAssembly, publié par le projet ffmpeg.wasm). Il est compilé avec des bibliothèques GPL, notamment x264 et x265
(FFmpeg configuré avec --enable-gpl), ainsi que libvpx, LAME, Theora, Vorbis, Opus, zlib, libwebp, FreeType,
FriBidi, libass et zimg. Ce composant est distribué sous licence GPL : https://www.gnu.org/licenses/
Informations légales de FFmpeg : https://ffmpeg.org/legal.html

Offre écrite de sources : le code source correspondant à ce composant se trouve chez ses auteurs :
- ffmpeg.wasm, commit 71aa99d3 ("RELEASE: @ffmpeg/core and @ffmpeg/core-mt v0.12.10") :
  https://github.com/ffmpegwasm/ffmpeg.wasm/commit/71aa99d37c02a7b4c435275ca9ef50e612f6efa1
  (scripts de compilation ; ils téléchargent les sources de FFmpeg, x264, x265 et des autres bibliothèques) ;
- FFmpeg : https://ffmpeg.org/ ; x264 : https://www.videolan.org/developers/x264.html ; x265 : https://www.x265.org/.
L'archive MediaDownloader-sources-<version>.tar.gz de la page de release contient seulement les sources de
MediaDownloader (dont tools/fetch-lite-assets.mjs, qui fixe l'adresse et la somme SHA-256 exactes du composant) ;
elle ne contient pas les sources de FFmpeg, x264 ni x265. Pendant au moins trois ans après la dernière
distribution de cette version, vous pouvez demander une copie du code source correspondant en ouvrant une issue
sur le dépôt GitHub du projet.

Autres composants embarqués :
- Pyodide 314.0.7 : MPL-2.0, avec la bibliothèque standard CPython (licence PSF) ;
- yt-dlp : Unlicense ;
- yt-dlp-ejs : Unlicense, avec meriyah (ISC) et astring (MIT) ;
- QuickJS-ng 0.18.0 compilé en WASI : MIT.
